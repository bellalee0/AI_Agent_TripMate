# 🧳 TripMate — 모임/여행 AI 에이전트 서비스

## 📌 프로젝트 소개

### 프로젝트 개요

- **프로젝트명(개발용)**: TripMate — 실제 서비스 오픈 시에는 '말만해'라는 이름을 고려 중
- **목적**: 학습용 AI 에이전트 서비스 개발 (개인 프로젝트)
- **핵심 시나리오**: 친구들과 1박 2일 여행을 목표로 이야기를 시작하지만, 일정이 안 맞으면 저녁 한 끼 모임으로 자연스럽게 축소되는 경우가 많음 → 이를 서비스 흐름 자체에 반영
- **서비스 범위**: 국내 한정, 장기 여행부터 단발성 약속(저녁 식사 등)까지 하나의 흐름으로 커버
- **핵심 차별점**: 방 생성 시 사람이 직접 "여행" / "번개" 유형을 선택하지 않음. AI가 일정 조율 결과를 분석해 모임 규모를 제안하고, 이후 단계(컨셉·장소·세부일정·경비)가 자동으로 그에 맞게 조정됨

### 전체 서비스 흐름

| 단계 | 기능 | 비고                                                                                                                               |
| :--: | :--: |:---------------------------------------------------------------------------------------------------------------------------------|
| 1 | 그룹/친구 제도 | 로그인 회원끼리 그룹방 생성, 비밀번호 참가, 팔로우 관계 기반 초대, 방장 권한(멤버 삭제·설정 변경·방장 위임)                                                                 |
| 2 | 일정 정하기 | 이미 정해졌으면 패스. 미정 시 각자 가능/불가능 날짜를 캘린더에 표시 → AI가 겹치는 구간 분석 → 최적 날짜 추천(확정 후 개인 로컬 캘린더 저장)<br>이 결과가 이후 모임 규모(여행/반나절/식사 등)를 결정하는 기준이 됨 |
| 3 | 여행 컨셉 키워드 선택 | 여유/액티비티 등 컨셉 선택 → 멤버별 선호/비선호 선택 → 비선호 제거 후 선호 기반 추천 리스트 생성                                                                       |
| 4 | 장소 정하기 | 이미 정해졌으면 패스. 미정 시 최근 유행 장소 + 컨셉 기반 추천                                                                                            |
| 5 | 세부 여행 내용 키워드 선택 | 산책·낚시·놀이공원·파티 등 선호, 비선호 음식·웨이팅 등 비선호 선택 → 지도 API로 이동시간·동선 계산 → 최적 세부 일정 및 숙소 추천                                                  |
| 6 | 예상 경비 책정 | 숙소, 입장료, 예상 식비 등을 종합해 사전 예상 경비 산출                                                                                                |
| 7 | 그룹 채팅 + AI 호출 | 그룹 채팅방 운영, '@' 태그로 AI 직접 호출 → 일정/경비 등 조율 요청 가능                                                                                   |
| 8 | 경비 계산 및 정산 | 영수증 검토 여부, 계산 담당자 지정 등 그룹 설정 → 항목·금액·해당 멤버 입력 지원 → 여행 후 누가 누구에게 얼마를 보내야 하는지 자동 정산                                                |
